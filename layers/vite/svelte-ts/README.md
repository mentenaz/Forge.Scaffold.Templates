# {__projectName__}

A Svelte and TypeScript project made with Mentenaz Forge. It is built with Svelte, TypeScript and Vite.

## Scripts

- `npm run dev` starts the development server with hot reload.
- `npm run build` makes a production build in `dist/`.
- `npm run preview` serves the production build locally.

## Where things are

- `src/main.ts` starts the app and `src/App.svelte` is the page you see first.
- `src/lib/Counter.svelte` is the counter.
- `public/` holds files served as they are, such as the favicon.
- `vite.config.ts` is the build configuration.

The Mentenaz Forge favicon (`public/favicon.svg`) and the image on the first page (`src/assets/hero.png`) are yours to keep,
change or remove.
